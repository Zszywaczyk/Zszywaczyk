### 🔧 What I do

I sit somewhere between **code and design** — which means I can take a project from a blank Figma canvas all the way to a production WordPress site. Most of my work revolves around:

- 🌐 **Custom WordPress & WooCommerce** — themes from scratch, no page builders, optimized for speed
- 🎯 **Tracking & Analytics** — custom Facebook Conversion API implementations (yes, the ones that bypass AdBlock)
- 🎨 **Graphic Design** — branding, social media campaigns, marketing materials
- 🧊 **3D Modeling** — product visualizations and technical models
